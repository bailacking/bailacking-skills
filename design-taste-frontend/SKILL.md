# 前端审美提升（design-taste-frontend）

## 定位
把「能跑但丑、像 AI 批量生成的界面」升级成「有设计意图、有辨识度」的界面。核心是**逼自己先做选择**，而不是掉进模型默认的「最安全平均脸」。

## 何时用
- 写新网页 / 落地页 / 后台 / 组件，且希望好看、有风格。
- 改现有 UI，想摆脱模板感。
- 主人说「美化一下」「别这么 AI 味」「提升审美」「设计感强一点」。

## 设计思维（动手前先想清楚）
1. **Purpose**：这界面解决啥问题？谁用？
2. **Tone**：选一个**极端**方向，执行到底——极简、极繁、复古未来、有机自然、奢华精致、编辑杂志风、野兽派、装饰艺术、柔和粉彩、工业实用……别选「干净现代」这种等于没选的词。
3. **Constraints**：技术约束（框架、性能、无障碍）。
4. **Differentiation**：什么是让人记住的那一个点？

> 关键：选一个清晰的方向，**精准执行**。大胆极繁和克制极简都行，要的是「有意图」，不是「用力过猛」。

## 三拨盘（核心配置）
读完需求后设三个值，之后所有布局/动效/密度决策都被它们 gate。默认值 `8 / 6 / 4`，除非需求覆盖——**别让用户改文件，对话里覆盖即可**。

- `DESIGN_VARIANCE: 8` — 1=完美对称网格，10=艺术混乱实验布局
- `MOTION_INTENSITY: 6` — 1=静态无动效，10=电影级物理动效
- `VISUAL_DENSITY: 4` — 1=艺术馆留白，10=驾驶舱密集数据

场景预设：SaaS 落地页 `7/6/4`；创意工作室 `9/8/3`；政府/公共 `3/2/5`；后台仪表盘 `4/3/8`。

## AI Slop 禁令清单（除非需求明确要求，否则禁止）
**视觉/CSS**
- 默认不上霓虹/外发光；不用纯黑 `#000000`；不超饱和点缀色；不做渐变文字；不用自定义鼠标光标。
- 配色一致性锁定：全站一个强调色；形状一致性锁定：全站一套圆角。

**排版**
- 默认别用 Inter（也避 Roboto/Arial/系统字体）；H1 别大得离谱；衬线字体有纪律（不随意混搭）。

**布局/间距**
- 禁止「三等分功能卡片一排」（无层级）；允许不对称、重叠、对角线、破网格。

**内容/数据（"张三效应"）**
- 禁止通用人名（John Doe / 张伟）、通用头像、假完美数字、创业废话品牌名（Acme/Nexus）、填充动词（Elevate/Seamless/赋能/无缝）。

**外部资源**
- 不手搓 SVG 图标（用图标库）；不 div 伪造截图；不用会挂的 Unsplash 外链。

**生产测试痕迹（直接禁令）**
- Hero 区版本标签（V0.6/BETA）、section 编号眉标（00/INDEX）、装饰性「·」分隔符过量、em-dash 滥用。

**Em-dash 绝对禁令（最常被犯）**
- 页面上**任何地方**禁止 em-dash `—`。只允许普通连字符 `-` 和数学减号 `-5°C`。

## 预检清单（输出代码前必跑，非可选）
- [ ] 已声明需求推断（一句话）
- [ ] 三拨盘数值已从需求推断并写明
- [ ] 适用时选了设计系统（不混 Material + shadcn）
- [ ] **零 em-dash** 全页
- [ ] 主题锁定：全站一个主题
- [ ] 配色锁定：一个强调色
- [ ] 形状锁定：一套圆角
- [ ] 每个 CTA 文字可读（对比度达标）
- [ ] CTA 标签桌面端不折行
- [ ] 不用 `window.addEventListener('scroll')`（用 Motion `useScroll()`/ScrollTrigger）
- [ ] `MOTION_INTENSITY>3` 时包 reduced-motion

## 重设计协议（改现有项目时）
1. **先判模式**：全新 / 保留式重设计 / 推翻式重设计。
2. **动手前先审计**：品牌 token、信息架构、内容块、要保留/淘汰的模式、拨盘读数、SEO 基线。
3. **保留规则**：不改信息架构；先提取品牌色；保留文案口吻；尊重无障碍与分析。
4. **现代化杠杆（优先级）**：①排版焕新 ②间距与节奏 ③配色重校 ④动效层 ⑤Hero 重组 ⑥整块替换。
5. **永不静默改动**：URL slug、导航标签、表单字段、Logo、法律文案。
